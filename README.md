# FarmAssist Climate Intelligence website

Public-facing project website for **FarmAssist Child Climate & Nutrition Intelligence**, an early open-source, offline-first climate-risk reference implementation by JOITA BIOSEED AI PRIVATE LIMITED.

The site presents the working prototype, offline architecture, explainable reference risk engine, synthetic demonstration evidence, data-safety model, measurable indicators, proposed 12-month roadmap, funding request, open-source scope, and validation limitations.

- Live site: https://farmassist-climate-open.algalomics.chatgpt.site
- Public synthetic demo: https://prakau.github.io/farmassist-child-climate-open/
- Public prototype: https://github.com/prakau/farmassist-child-climate-open
- Website source: https://github.com/prakau/farmassist-child-climate-open-website

## Local development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
npm test
npm run lint
```

The site is intentionally content-only: it does not collect visitor data, accept submissions, or require authentication.

## Responsible communication

The project is not a medical device or emergency-warning system. It does not claim validated child-health or nutrition outcomes, active school pilots, model accuracy, UNICEF endorsement, selection, partnership, or funding. The prototype requires independent agronomic, safeguarding, accessibility, security, and field validation.
